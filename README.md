# Rasar Demo App

`rasar_demo_app` is a minimal Frappe/ERPNext demo app used by Rasar Cloud to validate the external distribution flow with RasarCheck.

It is intended for technical validation of:

- protected app structure;
- RasarCheck catalog visibility;
- artifact generation;
- signed manifest validation;
- checksum validation;
- external installation preparation.

This app does not contain real premium logic, remote integrations, tokens, secrets, or production licensing rules.

Initial version: `0.1.0`.
